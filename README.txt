 うんこクエスト  ホーム画面アプリ化の手順
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【入っているファイル】
  index.html               … ゲーム本体（ファイル名は変えないこと）
  manifest.json            … アプリ名・アイコン・横向き固定の設定
  sw.js                    … オフラインで遊ぶための仕組み
  icon-180/192/512.png     … アプリアイコン
  icon-maskable-512.png    … Android用アイコン
  favicon.png              … タブに出る小さいアイコン

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 STEP 1  GitHub にアップする
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 1. github.com で新しいリポジトリを作る
      名前: unko-quest ／ Public を選択
      （Add a README は チェックしなくてOK）
 2. 「uploading an existing file」をクリック
 3. このフォルダの中身を【全部まとめて】ドラッグ＆ドロップ
      ※フォルダごとではなく、中のファイルを選んで入れること
 4. 下の「Commit changes」を押す

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 STEP 2  GitHub Pages を有効にする
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 1. リポジトリの Settings（歯車）を開く
 2. 左メニューの Pages をクリック
 3. Branch を  main  /  (root)  にして Save
 4. 1〜2分待つと 上に URL が表示される
      https://（ユーザー名）.github.io/unko-quest/

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 STEP 3  iPhone のホーム画面に追加
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 1. Safari で STEP 2 の URL を開く
 2. 下の 共有ボタン（□に↑）をタップ
 3. 下にスクロールして「ホーム画面に追加」
 4. 名前を確認して「追加」

 → ホーム画面に💩アイコンができる
 → タップすると アドレスバーなしの全画面で起動
 → 横向きレイアウト（左＝十字キー／右＝ABボタン）

 ※Android の Chrome は「アプリをインストール」が出ます

 知っておくとよいこと
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 ・一度ひらけば 圏外でも遊べます
 ・セーブと描いたドット絵は 端末の中に保存されます
   （Safariの履歴やサイトデータを消すと消えます）
 ・ゲームを更新したいときは GitHub の index.html を
   差し替えて、sw.js の「unkoq-v1」を「unkoq-v2」に
   書き換えると 新しい版が反映されます
 ・Public リポジトリなので 誰でもURLを見られます
